# 2026-10-22 Debug 記錄

## 1. 問題現象

LINE webhook URL verify = error，且貼文後 bot 無反應，未生成 Excel 檔案。

## 2. 根本原因

### 2.1 LINE SDK 的 `add()` 方法使用錯誤

```python
# 錯誤用法（add 是裝飾器，需要 @ 語法）
webhook_handler.add(MessageEvent, create_handler())

# 正確用法
webhook_handler._WebhookHandler__add_handler(create_handler(), MessageEvent)
```

### 2.2 uvicorn --reload 模式問題

在 `--reload` 模式下，lifespan 在監控進程運行，但請求由 worker 進程處理，導致 handler 未註冊。

**解決方案**：直接使用 `--reload` 模式啟動 uvicorn，並在 webhook 函數中確保 handler 已註冊。

## 3. 修復內容

### 修改檔案：`app/main.py`

**變更 1**：修正 handler 註冊方式
```python
# 原代碼
webhook_handler.add(MessageEvent, create_handler())

# 修改後
webhook_handler._WebhookHandler__add_handler(create_handler(), MessageEvent)
```

**變更 2**：在 webhook 函數中確保 handler 註冊
```python
if not app.state.webhook_handler._handlers:
    app.state.webhook_handler._WebhookHandler__add_handler(create_handler(), MessageEvent)
```
