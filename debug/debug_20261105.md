def _format_reply(self, date_str, court, name_list, ...):

## 三、發現的程式 Bug

### Bug 1：無效日期未驗證 ⚠️

**現象**：`11/31`、`13/45` 等無效日期被接受，甚至成功建立 Excel 檔案。

**根因**：`_calculate_expiry()` 中例外被靜默吞掉。

```python
# message_parser.py:315-320（修改前）
try:
    target_date = datetime(year, int(month), int(day))  # datetime(2026, 11, 31) 拋 ValueError
    if target_date.date() < today.date():
        is_expired = True
except:
    pass  # 靜默吞掉錯誤！is_expired 保持 False
return full_date, is_expired  # 返回 2026/11/31, False
```

**後果**：
- `11/31 PM TS -1` 解析成功，`is_expired=False`
- `filename_engine` 使用原始 month/day 生成檔名 `2026_11_31-PM.xlsx`
- 即使用了無效日期，仍成功建立 Excel 檔案

**驗證腳本**：
```python
python3 -c "
from datetime import datetime
try:
    datetime(2026, 11, 31)  # 拋 ValueError
except ValueError as e:
    print(f'錯誤: {e}')  # day is out of range for month
"
```

**日期驗證規則**：
| 輸入 | 11月天數 | 結果 |
|------|---------|------|
| `11/30` | 30天 | ✅ 有效 |
| `11/31` | 30天 | ❌ 無效 |
| `2/30` | 28/29天 | ❌ 無效 |
| `13/1` | 無13月 | ❌ 無效 |

### Bug 2：`_extract_name_list()` 無法過濾 `\`

**現象**：公告中 `20. \` 和 `21.\` 的 `\` 不會被 `.strip()` 清除。

```python

name = match.group(1).strip()
if name and not name.startswith('後補') and '限制' not in name:
    names.append(name)
```

- 輸入 `20. \` → `.strip()` 後仍是 `\`
- `\` 不為空字串，通過過濾
- LINE 中 `\` 不可見，看起來像空行，但會被计入人名

## 四、修復方案

### 修改 1：`_calculate_expiry()` 新增 `is_valid` 驗證

**檔案**：`app/parsers/message_parser.py`

```python
# 修改後
def _calculate_expiry(self, date_str: str) -> tuple:
    """計算 full_date、is_expired 與 is_valid
    
    Returns:
        (full_date, is_expired, is_valid)
        - is_valid=False 表示日期無效（如 11/31），應拒絕處理
    """
    today = datetime.now()
    month, day = date_str.split('/')
    
    year = today.year
    if int(month) < today.month:
        year += 1  # 跨年份邊界
    
    full_date = f"{year}/{month}/{day}"
    
    is_expired = False
    is_valid = True
    try:
        target_date = datetime(year, int(month), int(day))
        if target_date.date() < today.date():
            is_expired = True
    except ValueError:
        # 日期無效（如 11/31、13/45），標記為不合法
        is_valid = False
    
    return full_date, is_expired, is_valid
```

- 將所有 `registration.name in n` 改為 `n.strip() == registration.name.strip()`
